# Milestone 05 — sidebar and navigation

Completed 8 November 2026 (Asia/Jakarta). The primary sidebar contains exactly Dashboard, Ujian, Mata Pelajaran, Streaks, Leaderboard, Disematkan, Update List and Profil, in that order. Help, account/logout and a system/light/dark selector are utilities. No billing or upgrade action is invented.

Selected lessons expose Belajar (existing journey), Catatan, Mindmap, Kuis, Flashcard, Sumber, Tanya AI, Podcast and Tempel. Video appears for a relevant video source. Summary, research, translation, study planning and recovery remain in contextual tools. Legacy tabs are hidden only when the lesson navigation replaces them; source-free tools retain their controls. Primary dashboard pages do not display lesson tabs. Existing view/tool URLs remain usable, with additional home/ujian/flashcards/mindmap/update aliases.

The mobile drawer uses modal semantics, a backdrop, inert background, a focus trap, Escape and focus return. Closed or desktop-collapsed navigation is inert and hidden from assistive technology; aria-expanded tracks the actual state and viewport. Active destinations expose aria-current. History navigation preserves routes; unsafe active AI work keeps the current URL instead of leaving mismatched history. Safe background uploads allow navigation and complete in their own source without replacing the learner's current page or lesson.

Validation: 130 tests pass; build and lint pass (53 application modules plus inline scripts). Dedicated navigation browser checks pass eight primary routes, back/forward, desktop collapse, mobile inertness, focus cycling/Escape/return, contextual views, old aliases, note preservation and navigation during a held upload response. Dashboard checks pass all 12 viewport/theme combinations. Design checks pass semantic contrast, system theme, reduced motion and landing widths. The design test now waits for the browser's asynchronous media-change event before asserting the theme; no theme implementation workaround was needed.

Research: WAI's modal-dialog pattern (https://github.com/w3c/aria-practices/blob/main/content/patterns/dialog-modal/dialog-modal-pattern.html) was retrieved and used for focus containment, inert background and focus restoration. This is targeted accessibility testing, not a comprehensive assistive-technology certification. User-provided screenshots informed broad navigation organization without copying proprietary assets.

Live Gemini and fresh competitor-site access remain blocked by environment policy. The configuration draft is saved, but requires user review, Save and Publish in environment settings; the Gemini value belongs in the secret field, not application code. The credential supplied in chat was not transmitted, logged, or committed. No production deployment or live OCR accuracy claim is made. Milestone 06 has not started.
